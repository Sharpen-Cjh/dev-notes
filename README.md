# 개발 노트 (카테고리별 전자책)

여러 프로젝트를 진행하면서 배운 개념들을 카테고리별로 정리해나가는 개인 학습 자료입니다. 새 프로젝트를 할 때마다, 새로운 개념이 나올 때마다 계속 누적됩니다.

## 카테고리

- [`language/`](language/) — 프로그래밍 언어 자체의 문법/개념 (Kotlin, 나중에 다른 언어 추가 가능)
- [`frontend/`](frontend/) — 화면/UI 관련 (지금은 Android Jetpack Compose)
- [`backend/`](backend/) — 서버/의존성 주입/아키텍처 관련
- [`db/`](db/) — 데이터베이스 관련
- [`system/`](system/) — OS, 파일 시스템, 스레드/동시성 등 시스템 레벨
- [`network/`](network/) — 네트워크 통신 관련
